# Portfolio ludd.mov

Todo está en `index.html`. Los videos se reproducen dentro de la página.

## Cargar trabajos
Abrí `index.html`, buscá el bloque `EDITÁ ESTO` y completá una línea por trabajo en `WORKS`.
En `url` podés poner:
- El nombre de un archivo de video subido al repositorio (ej. `mi-video.mp4`, sin espacios en el nombre).
- Un enlace de YouTube, TikTok o Instagram (reel).

Opcional: `poster:"portada.jpg"` (imagen de la tarjeta) y `wide:true` (video horizontal).

## Subir archivos de video
En el repositorio: Add file → Upload files. Desde la web, cada archivo puede pesar hasta 25 MB.

## Publicar en GitHub Pages
Subí `index.html` y `README.md` a la raíz de un repositorio público, y en Settings → Pages elegí `main` y `/ (root)`.

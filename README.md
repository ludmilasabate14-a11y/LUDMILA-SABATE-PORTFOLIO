# Portfolio ludd.mov

Página de una sola pieza: todo está en `index.html`.

## Editar trabajos y contacto
Abrí `index.html`, buscá el bloque `EDITÁ ESTO` (cerca del final) y cambiá:
- `CONTACT_URL`: el enlace del botón de contacto.
- `WORKS`: una línea por trabajo, con `title`, `type` y `url` (enlace al video). Sin `url` se muestra "Próximamente".

## Publicar en GitHub Pages
Subí `index.html` y `README.md` a la raíz de un repositorio público, y en Settings → Pages elegí la rama `main` y `/ (root)`.
